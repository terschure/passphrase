# Passphrase code documentation

This documentation describes the different sub-systems which integrate together to provide the passphrase game experience.

The majority of the codebase was rapidly prototyped with the help of Claude Code & Codex, so this documentation was largely compiled after the fact to provide further structure.

Sub-systems:
- Game Loop
- UI
- ASCII Effects
- Voice recognition
- Processing



Supporting technologies:
- Browser
- HTML
- CSS
- Javascript
- Python
- Qwen3.6 TTS
